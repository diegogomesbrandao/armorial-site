    Jogar, exportar e arquivos

    17. Jogar, exportar e arquivos do projeto

    O botão Jogar roda o projeto dentro do editor, para testar sem sair dele.

    O botão Exportar gera um único arquivo .html que abre com dois cliques em qualquer computador, sem o editor e sem internet. Antes de exportar, o editor prepara o arquivo com todos os modelos, sons e imagens.

    Se o projeto não puder ser salvo, o editor pede para escolher outra pasta. Cada projeto é uma pasta criada pelo Armorial, com os modelos e sons dentro dela.

    O arquivo do projeto guarda, em formato JSON (formato gameproj, versão 1), as seguintes partes: meta (nome e modelo de origem), assets (imagens, modelos e sons), settings (gravidade e entradas), variables, prefabs (moldes), scenes (cenas com a árvore de objetos), eventSheets (planilhas de eventos) e audio (quando houver música adaptativa).

    A iluminação de ambiente usa imagens HDRI, que dão luz e reflexos sem aparecer no fundo. O editor traz três: Kloofendal (usado como Céu), Brown Photostudio (Estúdio) e Shanghai Bund (Cidade). Todas são de domínio público (CC0), vindas do Poly Haven, e ficam dentro do jogo exportado.

    A qualidade gráfica pode ser alta, média ou baixa. A versão alta tem sombras suaves e efeitos completos, e a baixa dispensa sombras e efeitos pesados. Há também uma opção de resolução de renderização: automática (que reduz quando o FPS cai), 100%, 75% ou 50%.

    Armorial versão 0.1.146. Editor de jogos com programação visual, feito para o ensino técnico.
