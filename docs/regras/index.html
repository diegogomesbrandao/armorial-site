    Como as regras funcionam

    8. Como as regras funcionam

    Cada regra é um evento. Ele tem um gatilho ou uma lista de condições e, em seguida, uma lista de ações. Quando as condições valem, as ações rodam em ordem, de cima para baixo. Por padrão, todas as condições precisam valer ao mesmo tempo. Para aceitar qualquer uma delas, use a condição Ao menos uma das condições de dentro vale.

    Existem dois tipos de verificação, e confundi-los é o erro mais comum de iniciantes.

    O gatilho passa uma vez, no instante em que o fato acontece. Exemplo: Começou a encostar em.

    A condição vale enquanto a situação durar. Exemplo: Botão está segurado, ou Está no chão.

    Um evento formado só por condições de estado roda a cada quadro, cerca de 60 vezes por segundo, enquanto as condições valerem. Para que a ação aconteça uma única vez, use Só uma vez enquanto as de cima valerem.

    As ações rodam uma depois da outra. O bloco Esperar N segundos pausa as ações seguintes. O bloco Repetir faz as ações do evento rodarem N vezes no mesmo instante.

    Cada ação ou condição de objeto informa o alvo, ou seja, a quem se aplica. O alvo pode ser o próprio objeto (em planilhas de objeto), um objeto escolhido, todos os objetos com uma tag, ou o objeto escolhido por uma condição anterior, como a moeda que o herói acabou de tocar.

    A planilha tem um escopo. Uma planilha de cena vale durante a fase inteira. Uma planilha de molde vale para cada cópia criada. Uma planilha de objeto vale só para aquele objeto.

    Eventos podem ser organizados em grupos e comentados. A ação Ligar ou desligar grupo liga ou desliga um conjunto inteiro de regras durante o jogo, o que permite, por exemplo, usar regras diferentes na fase 2.

    Exemplo do modelo Plataforma 2D: quando o herói começa a encostar num objeto com a tag moeda, o objeto encostado é destruído, a variável Moedas soma 1 e toca o som moeda. Essa regra inteira cabe em três blocos de ação, e é um bom ponto de partida para entender a lógica do editor.
