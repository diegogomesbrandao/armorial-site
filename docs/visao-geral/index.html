    Visão geral e primeiros passos

    1. Visão geral

    O Armorial é um editor de jogos feito para o ensino técnico em multimídia e design. Quem usa não escreve código: monta regras com blocos, no formato “quando isto acontece, faça aquilo”. Com ele dá para criar jogos 2D (plataforma, tiro, corrida, voo) e 3D (primeira pessoa, plataforma, kart, defesa com torres). O resultado final sai como um único arquivo HTML que roda sem internet.

    O aplicativo é um programa para Windows feito com Tauri 2 (Rust com interface web). A parte gráfica e de física usa Babylon.js, cujos módulos aparecem no pacote. As regras do Armorial, porém, têm formato próprio, baseado em planilhas de eventos com nomes em português.

    2. Primeiros passos

    A tela inicial tem três abas: Início, Projetos e Modelos.

    • Continuar de onde parei: reabre o último projeto trabalhado.
    • Novo projeto: cria um projeto em branco.
    • Projetos: lista os projetos salvos, com pesquisa, favoritos e opção de remover da lista.
    • Modelos: jogos prontos para começar (ver seção 16). Tudo pode ser mudado depois.

    O texto de ajuda do próprio editor sugere este primeiro caminho: abra um modelo em Modelos, aperte Jogar e depois mude uma regra na aba Eventos.

    Arquivos aceitos: imagens para sprites e texturas (PNG nos modelos prontos), modelos 3D no formato .glb (o editor orienta exportar do Blender como glTF 2.0 .glb) e sons em .mp3, .wav ou .ogg.
