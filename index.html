Crie jogos sem programar.

Monte regras com blocos em um editor de jogos 2D e 3D. Cada jogo sai num único arquivo, em HTML para o navegador ou em EXE para o Windows.

Três passos até o primeiro jogo

  1. Monte as regras

    Escolha um gatilho, condições e ações. Cada regra se lê como uma frase.

  2. Teste na hora

    O botão Jogar roda o projeto dentro do editor, sem sair dele.

  3. Exporte o jogo

    Escolha HTML, para abrir em qualquer navegador, ou EXE, para Windows. Os dois rodam sem o editor e sem internet.

Um jogo feito no Armorial.

Monte a cena.

Use formas, sprites, textos, luzes, câmeras e modelos 3D. Moldes criam cópias que herdam as regras, como uma moeda ou um inimigo.

  • Adicione

    Coloque formas, sprites e modelos .glb na cena.

  • Agrupe com tags

    Marque objetos com uma etiqueta e escolha todos de uma vez nas regras.

  • Repita com moldes

    Cada cópia recebe as regras do molde, e cada uma tem as suas variáveis.

Regras que se leem como frases.

Um evento junta um gatilho ou condições e uma lista de ações. Quando as condições valem, as ações rodam de cima para baixo.

  • Gatilhos

    Passam uma vez, no instante em que algo acontece. Ex.: começou a encostar em moeda.

  • Condições

    Valem enquanto a situação durar. Ex.: botão de pular está segurado.

  • Ações

    Fazem algo acontecer. Ex.: destruir objeto, somar na variável, tocar som.

Movimento, animação e som.

Dê vida aos objetos sem escrever uma linha de código.

  • Comportamentos prontos

    Plataforma, kart, primeira pessoa, inimigo que persegue e mais 16 comportamentos.

  • Animação

    Animador de personagens com estados e uma linha do tempo para clipes próprios.

  • Música adaptativa

    A trilha muda conforme o jogo avança, com camadas que entram e saem.

Por dentro do editor

Tudo fica numa única janela: cena, regras, animação, partículas, interface e som.

Perguntas frequentes

Preciso saber programar?

Não. Você monta as regras com blocos, como frases do tipo quando isto acontece, faça aquilo.

O Armorial roda no navegador?

O editor não: ele é um programa para Windows. O jogo exportado, sim, como arquivo HTML que abre em qualquer navegador. Também dá para exportar como EXE, que roda no Windows sem o editor.

Os jogos exportados precisam de internet?

Não. Tanto o HTML quanto o EXE levam os modelos, sons e imagens do jogo.

Funciona em Mac ou Linux?

Por enquanto, só Windows. Mac e Linux não estão no lançamento.

Posso usar em aula?

Sim. Os primeiros passos são o caminho mais curto até um primeiro jogo. Trilhas de aula prontas ainda estão planejadas.

Quanto custa?

Nada. O Armorial é gratuito.
