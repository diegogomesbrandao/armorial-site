Crie jogos montando regras, sem programar.

O Armorial é uma engine para criar jogos 2D e 3D com blocos visuais. Feito para quem estuda multimídia e design.

Baixar para Windows Ver a documentação

Para aprender a lógica dos jogos, não a sintaxe.

Toda a lógica do jogo é montada em listas: escolhe-se o que acontece, o que precisa ser verdade e o que o jogo faz. Não há código para digitar nem erros de sintaxe para caçar.

Dá para criar jogos de plataforma, tiro, corrida, voo e defesa, em 2D ou 3D. O jogo final sai como um arquivo HTML que abre em qualquer computador, sem internet.

Três ideias explicam quase tudo.

  • GatilhoUm fato que acontece num instante, como encostar numa moeda.
  • CondiçãoAlgo que precisa valer para a regra seguir, como estar no chão.
  • AçãoO que o jogo faz: mover, pular, somar pontos, tocar um som.
